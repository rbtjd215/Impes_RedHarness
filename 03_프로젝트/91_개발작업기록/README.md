# 개발 작업 기록

이 폴더에는 Codex와 팀원이 수행한 **작업별 인계**를 보관한다. 제품의 실행 결과나 원시 출력은 여기에 넣지 않는다. 이 저장소는 공개이므로 공개해도 되는 검증 요약만 남긴다.

- 첫 의미 있는 수정 또는 테스트 때 작업기록_템플릿.md를 복사해 YYYY-MM-DD_<team>_<task-id>.md를 만든다. team은 a, b, oracle, integration, common 중 하나다. 같은 날짜의 별도 작업은 고유 task-id로 구분한다.
- 한 작업/브랜치에 한 기록 파일과 한 명의 주 작성자를 둔다. 짝은 같은 파일을 동시에 수정하지 않고 PR 댓글 또는 자신의 기록으로 검토 결과를 전달한다.
- 중요한 편집·실행·실패·방향 변경 뒤에 체크포인트를 갱신한다. “작업 종료” 또는 “인계” 때 실제 Git 변경과 테스트를 다시 확인한다. 앱 종료 뒤 자동 기록은 보장되지 않는다.
- 변경 파일, 기준/종료 커밋·PR, 실제 시도와 관찰된 결과, 채택·폐기한 아이디어와 확인된 이유, 테스트 PASS/FAIL/SKIP, 막힘과 다음 행동을 적는다. 실행하지 않은 테스트는 SKIP과 이유를 쓴다.
- 전체 대화, 숨은 추론, 추측한 결정, 키·쿠키·비밀번호·개인정보, 민감한 대상 정보와 원시 실행 출력은 기록하지 않는다. 민감한 내용은 공개 PR에도 넣지 않는다.
- 재시작 때 최근 기록을 현재 브랜치·HEAD·diff·미추적 파일·PR과 대조한다. 차이가 있으면 실제 Git을 확인하고 먼저 알린다.

작업 브랜치와 짝 검토·팀장 통합은 ../00_공통/CODEX_개발협업.md를 따른다.
