# Dispatcher

기존 회장 배정으로 허용된 실행 요청에서 A(인증우회) 또는 B(XSS) 하나를 선택하고 공통 v1 봉투로 넘기는 담당 경로다. 아직 실행 코드가 없다. 입력·출력과 허용 대상은 [PROJECT_SPEC](../00_공통/PROJECT_SPEC.md)를 따른다.

담당 외 계약 변경은 영향받는 팀을 밝히고 개발 PR에서 검토한다. 현재는 [mock 계약 검사](../00_공통/검증/README.md)로 봉투 형식만 확인할 수 있다.

[최신 확인](../00_공통/작업시작_최신확인.md)과 [공통 협업 규칙](../00_공통/CODEX_개발협업.md)을 따른다. 자기 브랜치·PR·task-id의 인계를 우선하고 관련 팀의 현재 설계·실제 검증·겹치는 경로를 대조한다. 일반 팀 PR을 회장이 모두 승인·병합하는 게이트는 없다. 통합에서 각 팀의 인터페이스·단일 Oracle 판정·Reporter 보존과 실제 랩 미검증을 구분한다. 동아리장 공통 예외 승인이 민감한 공개를 허용하지 않는다.
