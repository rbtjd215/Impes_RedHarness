## 작업 동선과 반영 상태

첫 준비·매일 작업·업로드는 [공동 개발 사용 안내](00_공통/공동_개발_사용_안내.md)의 세 동선을 따른다. 최신 인계는 날짜보다 현재 브랜치·PR·task-id/수정 경로가 맞는 기록을 우선한다. 현재 채택 설계는 해당 팀 안내·설계 문서에서 확인하고 과거 기록은 필요한 범위만 읽는다. 통합은 기존 회장 배정이며 대행은 미확인이다.

2026-10-01 검토 시 main은 `f8db150`이고 환경 준비 PR #2는 미병합이다. 추가 시작·인계·협업 보완은 로컬 미업로드이며 학생 새 clone의 확정 규칙으로 안내하지 않는다. 자동 검사 파일·실제 CI 실행·GitHub 보호 설정을 구분한다. 학생 배포 전 실제 main 반영과 새 채팅/첫 기록/재시작을 실증한다.
