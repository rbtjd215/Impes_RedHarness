# RedHarness 3주차 제출 보고서 / Week 3 submission report

이 파일은 **빈 공통 양식**입니다. Codex가 실제 Git 상태·작업별 기록·확인 가능한 검사를 대조해 학생의 보고서를 작성하고, 학생은 사실만 확인합니다. 작성 언어는 한국어 또는 영어를 선택할 수 있지만 아래 **일곱 개 H2 제목과 순서**는 유지합니다. 과거 결과를 이번 결과로 복사하지 않습니다.

This is a **blank shared template**. Codex drafts the student's report from actual Git state, the task record, and checks it can verify; the student checks the facts. Write in Korean or English while keeping the seven H2 headings and their order.

완성된 보고서에서는 `template-id`를 유지하고 메타데이터에 `status: submission-report`를 추가하며, 확인된 사실의 요약 보고서임을 표시합니다. 이 빈 양식 소개 문단은 결과로 복사하지 않습니다. `status`는 작업이나 학습 완료 판정이 아닙니다. / In the generated report, keep `template-id`, add `status: submission-report` to the metadata, and identify it as a summary of verified facts. Do not copy these blank-template instructions into the result. `status` does not mean the task or learning is complete.

**상태 구분 / Status key:** 검사는 실제 결과에 따라 `PASS`·`FAIL`·`SKIP`(미실행 이유 포함)로 적습니다. 준비·검토·작업·공유의 진행 상태는 **완료 / 미완료 / 미확인 / 미실행 / 해당 없음** 중 확인된 값으로 적습니다. `SKIP`은 완료가 아니고, `해당 없음`은 검사 미실행을 숨기는 말이 아닙니다. 빈 양식의 “미확인/미실행”은 예시 성과가 아닙니다. **검사 `PASS/FAIL/SKIP`은 Oracle 실행 봉투의 `PASS/FAIL/UNKNOWN/NOT_RUN`과 다르며, 검사 PASS가 실제 하네스·랩 성공을 뜻하지 않습니다.**
