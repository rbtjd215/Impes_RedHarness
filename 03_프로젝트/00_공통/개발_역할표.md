# 공개용 개발 역할표

이 표는 **파트와 책임만** 적는다. 개인 이름·연락처·출결·주차 기록은 운영 Vault에서 별도로 관리하며 이 공개 저장소에 옮기지 않는다. 이름 확인은 Codex의 작업 안내용이고 접근 권한 검증이 아니다.

| 파트 | 주 책임 | 목표·기본 경로 |
|---|---|---|
| 팀장 · Dispatcher/통합 | 공통 연결·검토·최종 통합 | `03_프로젝트/01_Dispatcher/`, `03_프로젝트/05_통합/` |
| A · 인증우회 | 분야별 행동·관찰·증거 후보 | 자체 로컬 문제 L1 · `03_프로젝트/02_전문모듈_A/` |
| B · XSS | 분야별 행동·관찰·증거 후보 | 같은 하네스에서 L0 · `03_프로젝트/03_전문모듈_B/` |
| Oracle | 외부 근거로 최종 상태를 한 번 판정 | `03_프로젝트/04_Oracle_Reporter/` |
| Reporter | Oracle 상태를 바꾸지 않고 기록 | `03_프로젝트/04_Oracle_Reporter/` |

개인 주 책임과 짝의 실제 배정은 공개 정보로 확정하지 않았다. 작업자는 자신의 파트를 명시해 시작할 수 있다. 짝이 같은 입력을 재실행하거나 변경을 검토하고 PR에 결과를 남긴 뒤 팀장이 통합한다. 담당 밖 수정과 공통 계약 변경은 [협업 규칙](CODEX_개발협업.md)에 따라 영향 범위를 먼저 밝힌다.
