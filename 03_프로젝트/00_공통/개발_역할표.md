# 공개용 개발 역할표

이 표는 파트별 책임만 정의한다. 개인 이름·연락처·출결·평가 자료는 공개 저장소에 수집하지 않는다. 작업자가 어느 변경을 커밋했는지는 Git의 author/committer 메타데이터와 커밋 SHA·PR로 확인하되, 이 값은 신원 인증이 아니다. 각자 자기 변경을 직접 커밋해야 구분하기 쉽다.

| 파트 | 주 책임 | 목표·기본 경로 |
|---|---|---|
| Dispatcher/통합 | 공통 연결·전체 실행 | `03_프로젝트/01_Dispatcher/`, `03_프로젝트/05_통합/` |
| A · 인증우회 | 분야별 행동·관찰·근거 후보 | 자체 로컬 문제 L1 · `03_프로젝트/02_전문모듈_A/` |
| B · XSS | 분야별 행동·관찰·근거 후보 | 같은 하네스에서 L0 · `03_프로젝트/03_전문모듈_B/` |
| Oracle | 외부 근거로 최종 상태를 한 번 판정 | `03_프로젝트/04_Oracle_Reporter/` |
| Reporter | Oracle 상태와 근거를 바꾸지 않고 기록 | `03_프로젝트/04_Oracle_Reporter/` |

각 팀은 담당 목표 안에서 계획·구현·내부 절차·프로토타입 채택 여부를 자율적으로 정한다. 다른 팀에 영향을 주는 변경은 해당 팀과 조율한다. 공통 필수 계약·판정 책임·자동 실행 허용 범위의 변경이나 예외만 [협업 규칙](CODEX_개발협업.md)에 따라 동아리장의 명시 승인을 받는다. 현재 B 오프라인 mock은 참고용이며 팀의 채택 결정이 아니다.
