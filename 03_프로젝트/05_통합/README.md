# 통합

Dispatcher → 선택된 A/B → Oracle → Reporter의 한 실행을 연결하는 담당 경로다. 아직 통합 실행 코드와 허용된 로컬 랩 정보가 없다. [PROJECT_SPEC](../00_공통/PROJECT_SPEC.md)의 공통 계약과 자동 실행 정책을 따른다.

팀장은 Dispatcher·전체 연결의 통합 범위를 조정한다. 각 팀의 도입 여부는 해당 팀이 정하고, 별도 내부 검토·승인을 둘지도 해당 팀이 선택한다. 팀장이 모든 모듈 PR을 필수 승인·병합한다는 뜻이 아니다. 통합 작업에서는 각 파트의 실제 테스트와 `SKIP`, 계약 영향과 전체 흐름의 호환성을 확인해 결과를 기록한다. 공통 계약·최종 판정 책임·허용 범위 정책 변경은 동아리장의 명시 승인을 받는다. 실행 결과를 공개할 때는 비밀값·쿠키·개인정보·원시 `runs/`를 제외한다.
