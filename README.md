# RedHarness

**AI 에이전트의 실행을 설계하고, 결과를 근거로 검증하는 웹 보안 교육 프로젝트**

RedHarness는 2026년 2학기 IMPES 동아리에서 진행하는 프로젝트입니다. 허용된 자체 로컬 웹 보안 실습 환경에서 전문 모듈의 실행과 결과 검증·기록을 하나의 흐름으로 연결하는 하네스를 만드는 것을 목표로 합니다.

참가자는 기존 보안 에이전트의 구조를 살펴보고, 모듈의 입출력 설계부터 구현·검증·통합까지 함께 경험합니다.

## 프로젝트 구조

```text
입력 → Dispatcher → 전문 모듈 A 또는 B → Oracle → Reporter
```

| 구성요소 | 역할 |
|---|---|
| Dispatcher | 입력에 맞는 전문 모듈 선택과 요청 전달 |
| 전문 모듈 A | 인증우회 실습 문제의 분석·실행 |
| 전문 모듈 B | XSS 실습 문제의 분석·실행 |
| Oracle | 실행 근거를 확인해 최종 상태 판정 |
| Reporter | 판정 결과와 근거·실행 기록 보존 |

## 개발 현황

| 항목 | 현재 상태 |
|---|---|
| 공통 입출력 계약 | 작업 기준 마련 |
| 오프라인 mock 예제·검증 도구 | 가상 데이터로 흐름과 계약을 확인하는 예제·도구 제공 |
| 실제 모듈·로컬 랩·전체 통합 | 검증 전 |

B 모듈의 오프라인 mock 어댑터는 참고 예제입니다. 실제 인증우회·XSS 모듈의 실행, Oracle·Reporter의 실제 구현, 전체 통합과 로컬 랩 실행은 아직 검증되지 않았습니다.
